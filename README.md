# Student Planner

A simple, responsive student task planner built with **HTML, CSS, and JavaScript**.

## Features
- Add tasks with a subject and due date
- Mark tasks as completed
- Delete tasks
- Filter all, pending, and completed tasks
- Dashboard showing total, completed, and pending tasks
- Saves tasks in the browser using localStorage
- Responsive layout for mobile and desktop

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add your study tasks and manage your progress.

## Project structure
- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — task management and local storage

## Technologies
HTML5 · CSS3 · JavaScript
